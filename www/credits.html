Big Man Computer

BMC is an educational CPU simulator inspired by the Little Man Computer (LMC), a model created by Dr. Stuart Madnick in 1965. BMC enhances the LMC model with additional instructions and a modern web-based interface for interactive learning.

Built With

  • Novus — A compiled systems programming language. The entire BMC server is written in Novus and compiles to native ARM64/x86_64 code.
  • Nox — Package manager for Novus. Used to manage dependencies and project structure.

Novus Libraries Used

  • novus-std — Standard library (I/O, strings, utilities)
  • novus-net — Network sockets
  • novus-http — HTTP server framework
  • novus-file_io — File system operations
  • novus-process — Process management (fork, exec)
  • novus-env — Environment variables
  • novus-time — Time and timers
  • novus-maths — Mathematics functions

The Little Man Computer

The LMC was designed as a simple instructional model of a Von Neumann architecture computer. It features an accumulator, a program counter, and a fixed number of memory locations. BMC follows this design philosophy while adding enhancements to make it a more complete learning tool.

The LMC concept is in the public domain and is widely used in computer science education around the world, particularly in A-Level Computer Science courses in the UK.
