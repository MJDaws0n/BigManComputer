BMC Help

What is BMC?

Big Man Computer (BMC) is an enhanced version of the Little Man Computer (LMC), a simplified CPU model used to teach the fundamentals of how processors work. BMC extends LMC with additional instructions like multiplication, division, bitwise operations, and character output.

Programs are written in a simple assembly-like language and executed step-by-step in a virtual CPU, allowing you to watch registers change, memory update, and data flow through the system in real-time.

Assembly Syntax

Each line of a BMC program has the following format:

[label:]  OPCODE  [operand]  [; comment]
  • Labels are optional identifiers followed by a colon, used for branching and data references.
  • Opcodes are the instruction mnemonics (e.g., LDA, ADD, HLT).
  • Operands can be memory addresses (0-99) or label names.
  • Comments start with a semicolon and continue to end of line.
  • Blank lines and comment-only lines are ignored.
; Example: Add two numbers
start:  INP          ; Get first number from user
        STA num1     ; Store it at label 'num1'
        INP          ; Get second number
        ADD num1     ; Add the first number to accumulator
        OUT          ; Display the result
        HLT          ; Stop the program

num1:   DAT 0        ; Reserve storage, initialised to 0

InstructionOperandDescription

Arithmetic

InstructionOperandDescription
ADDaddress/labelAdd memory value to Accumulator

Input / Output

InstructionOperandDescription
INPnoneRead a number from user input into the Accumulator
OUTnoneOutput the Accumulator as a number
OTCnoneOutput the Accumulator as an ASCII character

Branching

InstructionOperandDescription

Virtual CPU Architecture

The BMC virtual CPU has the following components:

Registers

RegisterNameDescription
ACCAccumulatorThe main working register. All arithmetic and I/O goes through here.
PCProgram CounterHolds the address of the next instruction to execute.
MARMemory Address RegisterHolds the memory address currently being accessed.
MDRMemory Data RegisterHolds the data being read from or written to memory.
CIRCurrent Instruction RegisterHolds the instruction currently being executed.
SRStatus RegisterCPU flags: Zero (Z), Positive (P), Negative (N)

Memory

BMC has 100 memory locations (addresses 0-99). Each location can store an integer value. Instructions and data share the same memory space (Von Neumann architecture).

Fetch-Decode-Execute Cycle

Each step of execution follows this cycle:

  1. Fetch: Copy PC to MAR, read instruction from memory into MDR, copy to CIR, increment PC.
  2. Decode: Split the instruction into opcode and operand.
  3. Execute: Perform the operation (e.g., load data, arithmetic, branch).

Using the Editor

Controls

  • Load - Parse your code and load it into the virtual CPU memory.
  • Step - Execute one instruction and see the CPU state change.
  • Run - Run the program continuously (with a short delay between steps for visualization).
  • Reset - Reset the CPU to its initial state.

Input & Output

When an INP instruction is executed, the simulator will pause and ask for input. Type a number in the input field and press Send (or Enter). Output from OUT and OTC appears in the Output panel.

Example Programs

Countdown from Input

        INP          ; Get starting number
loop:   OUT          ; Display current value
        SUB one      ; Subtract 1
        BRP loop     ; If still positive, continue
        HLT          ; Done

one:    DAT 1        ; Constant: 1

Multiply Two Numbers

        INP          ; First number (multiplier)
        STA count
        INP          ; Second number (multiplicand)
        STA num
        LDA zero     ; Start result at 0
        STA result
loop:   LDA count
        BRZ done     ; If count is 0, we're done
        LDA result
        ADD num      ; Add multiplicand to result
        STA result
        LDA count
        SUB one      ; Decrement counter
        STA count
        BRA loop     ; Repeat
done:   LDA result
        OUT          ; Display result
        HLT

count:  DAT 0
num:    DAT 0
result: DAT 0
zero:   DAT 0
one:    DAT 1

Print "HI" Using Character Output

        LDA charH    ; Load ASCII 72 (H)
        OTC          ; Output as character
        LDA charI    ; Load ASCII 73 (I)
        OTC          ; Output as character
        HLT

charH:  DAT 72       ; ASCII 'H'
charI:  DAT 73       ; ASCII 'I'

Fibonacci Sequence

        LDA zero     ; a = 0
        STA a
        LDA one      ; b = 1
        STA b
        LDA count    ; Loop 10 times
        STA i
loop:   LDA a
        OUT          ; Output current number
        ADD b        ; next = a + b
        STA temp
        LDA b
        STA a        ; a = b
        LDA temp
        STA b        ; b = next
        LDA i
        SUB one
        STA i
        BRP loop
        HLT

a:      DAT 0
b:      DAT 1
temp:   DAT 0
i:      DAT 0
count:  DAT 10
zero:   DAT 0
one:    DAT 1
